Build a complete, production-quality full-stack web application called "ResumeIQ – AI Resume Analyzer".

GOAL:
Create an AI-powered Resume Analyzer where users can upload their resume as a PDF, select the job role they are applying for, enter their email address, and receive an AI-generated resume analysis both on the website and via email.

The application must be fully functional. Do NOT build a static demo or use hardcoded/mock analysis results.

--------------------------------------------------
1. RESUME UPLOAD
--------------------------------------------------

Create a modern drag-and-drop PDF upload interface.

Requirements:
- Accept PDF files only.
- Show selected filename and file size.
- Allow users to remove/change the uploaded file.
- Validate file type and reasonable file size.
- Extract the actual text/content from the uploaded PDF.
- Handle multi-page resumes.
- If the PDF is scanned/image-based, use an appropriate method to extract readable content when possible.
- Show a clear error if the resume cannot be read.

--------------------------------------------------
2. JOB ROLE SELECTION
--------------------------------------------------

Add a job-role dropdown containing:

- Backend Developer
- Frontend Developer
- Full Stack Developer
- Java Developer
- Node.js Developer
- Python Developer
- Software Engineer
- Data Analyst
- HR / Human Resources
- Other

If "Other" is selected:
- Display a text input for the custom job role.

Also provide an option:
"No specific role"

If no role is selected, evaluate the resume using general resume and ATS best practices.

--------------------------------------------------
3. EMAIL INPUT
--------------------------------------------------

Add an email address input field.

The user will enter the email address where the detailed resume analysis report should be sent.

Validate the email address before starting the analysis.

--------------------------------------------------
4. AI RESUME ANALYSIS
--------------------------------------------------

Use a real LLM API, preferably Google Gemini.

Do NOT use fake or hardcoded scores or feedback.

Send the extracted resume content and selected job role to Gemini.

Ask Gemini to analyze:

- Overall resume score out of 100
- ATS compatibility
- Resume strengths
- Missing skills
- Missing sections
- Weak content
- Formatting concerns
- Keyword optimization
- Role-specific skill matching
- Experience/project quality
- Education section
- Technical skills
- Actionable improvement suggestions
- Final recommendation

The AI should distinguish between:
- Information actually present in the resume
- Information that is missing
- Suggestions for improvement

Do not invent experience, education, skills, projects, companies, or achievements.

If a job role is selected, evaluate the resume specifically against that role.

--------------------------------------------------

--------------------------------------------------

Require Gemini to return structured JSON.

Use a structure similar to:

Validate the AI response before displaying it.

If the AI returns invalid JSON, handle the error gracefully rather than crashing the application.

Disable the Analyze button while processing.

6. Final Recommendation

Use icons, cards, badges, progress indicators, and clean spacing.

--------------------------------------------------

Generate a professional email report containing:

- Resume score
- ATS score
- Selected job role
- Summary
- Strengths
- Missing skills
- Missing sections
- Keyword suggestions
- Improvement suggestions
- Final recommendation

Send the report to the email address entered by the user.

Use real Gmail/email delivery.

IMPORTANT:

- If email sending fails, show an appropriate error message.
- The resume analysis should still be visible on the website even if email delivery fails.

After successful email delivery, show:

"📩 Your detailed resume report has been sent to your email successfully."

--------------------------------------------------
9. GMAIL CONFIGURATION
--------------------------------------------------

Implement email sending securely.

Do not put Gmail credentials in frontend code.

Use Replit Secrets/environment variables for all sensitive credentials.

Clearly document the required Gmail configuration and environment variables.

Do not expose:
- API keys
- OAuth credentials
- passwords
- tokens

in the frontend or GitHub repository.

--------------------------------------------------
10. SECURITY & PRIVACY
--------------------------------------------------

Resume files may contain personal information.

Therefore:

- Do not permanently store resumes unless necessary.
- Do not log resume contents unnecessarily.
- Do not expose uploaded files publicly.
- Keep API keys and email credentials server-side.
- Validate uploaded files.
- Validate user input.
- Never commit secrets to GitHub.
